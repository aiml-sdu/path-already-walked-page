A Path Already Walked

On inheriting network-neuroscience tools for mechanistic interpretability

Phongsakon Mark Konrad
Centre for Industrial Software, University of Southern Denmark, Sønderborg
Toygar Tanyel
Promake, Newark, DE, USA
Serkan Ayvaz
Centre for Industrial Software, University of Southern Denmark, Sønderborg
OpenReview ↗ PDF ↗ Code ↗ arXiv coming soon BibTeX

Mechanistic interpretability keeps changing its unit of explanation. It began with single neurons, then moved to attention heads, circuits, superposition, dictionary features and attribution graphs. The newest units are graphs. A statistic computed on such a graph can reflect preprocessing choices as much as the model.

Network neuroscience met this problem about two decades ago. It built graph measures, null models and a record of how those measures mislead. We argue that interpretability can borrow those tools as methods, on one condition: a graph claim must say exactly which graph it is about before anyone computes anything on it.

TL;DR

Network neuroscience has two decades of graph measures, null models and known failure modes, and we argue that mechanistic interpretability can use them as methods. The price is a transformer graph contract: each graph claim declares its nodes, edges, prompt distribution, threshold, null model and behavioural target before any statistic is computed. We map twelve network-neuroscience primitives to transformer questions, define a Jacobian measure of how strongly one component drives another, and state eight testable translations, each with the result that would refute it. We then ran one pre-registered test of two translations on GPT-2 small, and both predictions failed. The reasons, found after the test, show how much the edge construction and the null model decide.

Paper abstract

Mechanistic interpretability and network neuroscience both began by studying single parts, and both now ask how those parts are connected. Network neuroscience has spent two decades developing graph measures, null models, and known failure modes for this question. We argue that these tools can be adopted for transformers as methods, provided each graph claim first declares its nodes, edges, prompt distribution, null model, and behavioural target. We map network-neuroscience primitives to transformer questions, define a Jacobian measure of how strongly one component drives another, and state eight testable translations with explicit failure criteria. This is a position and methodology paper. Its one experiment, a pre-registered test of two translations on GPT-2 small, fails, and the reasons for the failure show how much the edge construction and the null model decide. We do not claim that neuroscience results transfer automatically.

01Background

Interpretability is retracing neuroscience's route from parts to wiring

Both fields started with parts that could be named, ablated and counted. Neuroscience had single cells, regions and lesion effects. Interpretability had neurons and attention heads.

Both then found units that respond to mixtures. Cells in prefrontal cortex mix task variables, and transformers represent more features than they have dimensions. Both reached for sparse coding, and sparse autoencoders now carry sparse coding's known problems: decompositions that are not canonical and feature atlases that change between runs.

Both now draw subgraphs. Neuroscience calls a recurring subgraph a motif and scores it against a null ensemble. Interpretability calls a prompt-local subgraph a circuit and finds it with patching or attribution. What network neuroscience adds is the habit of computing statistics over the whole population and comparing them with a null. The parallel is about method. We do not claim that transformers are brains.

02Proposal

A graph claim should say which graph it is about

A transformer induces many graphs. Nodes can be neurons, heads, SAE features or blocks. Edges can be weights, activation correlations, patching effects or Jacobians. Each choice of threshold, symmetrisation and prompt set can change the answer.

The transformer graph contract fixes those choices before any statistic is computed. Signed effects are projected or split into positive and negative graphs. Directed measures are not quietly swapped for undirected ones. Binary measures get a threshold or a density target, matched across models. The null keeps the architecture: layer order, density and degree sequence.

The result then has to pass two checks. Its statistic s(G) must lie outside what the null produces, and it must predict held-out behaviour better than component counts alone. If either check fails, the claim fails.

A null model can only test what it does not already build in

A null model is a random ensemble of graphs. It fixes what counts as chance. If the null lets layer order vary, a statistic that only reflects the architecture will look significant.

The rule is short. Keep every nuisance property that could produce the effect by construction, and randomise only the property under test. Choose a research goal to see what that means in practice.

06Definition

One way to measure how strongly a head drives another

Effective connectivity, the directed influence of one unit on another, is where network neuroscience and patching-based circuit work meet. A patching edge records the effect of a finite intervention. Our proxy records infinitesimal sensitivity instead: the size of the Jacobian block between two components, squared and averaged over prompts. The two measures complement each other.

Definition 1 · Gradient effective-connectivity proxy For upstream components 𝒜 and downstream components ℬ with declared intervention coordinates, let Jba(x) be the block Jacobian from 𝒜 to ℬ. Then
ECab(𝒳)=𝔼x∼𝒳‖Jba(x)‖F2

Writing the proxy down forces two declarations the contract asks for: signed or unsigned effects, and proxy or intervention. The statistics are then named too. A rich club is only meaningful against a degree-preserving null, so its coefficient is reported as a ratio to that null:

Φnorm(k)=Φ(k)Φrand(k)σ=C/CrandL/Lrand

A Jacobian proxy is not a causal intervention. Pairwise probing scales with the product of the two component sets; vector-Jacobian or Jacobian-vector products can often reduce the number of derivative queries, depending on batching, block size and memory.

07Pre-registered

We pre-registered a test of our own proposal. Both predictions failed.

A contract is only worth something if you hold yourself to it. We took the two cheapest translations, rich-club ordering and modularity, and tested them on GPT-2 small with indirect-object-identification (IOI) prompts. Every contract choice and both failure criteria were written into a pre-registration and hashed before any statistic was computed. Each test used a one-sided α = 0.025, a Bonferroni correction over the two.

The nodes are the 144 attention heads. The edges are the top 10% of the 9,504 admissible earlier-to-later head pairs by the Jacobian proxy, 950 edges in all. The null rewires the graph 1,000 times and keeps each head's in- and out-degree, the edge count of every layer pair, and layer order.

    Why it failed: the edges measured scale, and the null had no room to move

    The reasons below were found after the test, so they are not part of it. They are the paper's warning in concrete form.

    The raw Jacobian is dominated by the output scale of early heads. Mean EC is 161 for edges that leave layer 0 and 102 for layer 1, and between 5 and 8 for every later layer. So 927 of the 950 retained edges leave layers 0 and 1, and all 25 club heads sit in layers 0, 1 and 3. The "rich club" is a set of whole early layers.

    That is where the null runs out of room. Our null keeps each head's degree inside every layer pair. For a club made of whole layers, this also fixes the number of edges inside the club. Every null graph reproduced the observed coefficient, and the test had no power. Try it in Figure 2: rewire as often as you like and Φ stays at 0.21.

    The 10 strongest edges (EC ≈ 4–7 × 10³) and 10 random retained edges (EC ≈ 50–230) have similar finite effects. The proxy ranks edges only weakly as patching does.

    Threshold sensitivity

    Modularity, in turn, passes at 20% density (AMI 0.18, p = 0.02). The pre-registration lists 5% and 20% as report-only checks, so we do not count this as support. It is the threshold dependence the contract exists to expose.

    The example shows one contract failing, not the translations. A next test would pre-register a scale-normalised edge and a null that keeps only the global degree sequence and layer order. That would be a new pre-registration, not a re-analysis of this one.

    08Scope

    What this does and doesn't show

    This is a position and methodology paper with one experiment. The contracts and translations were tested once, on one small model and one task, and the test failed.

    It shows
    • How much the edge construction and the null model decide. On GPT-2 small they left the test with no power.
    • A contract and eight translations, each with a stated failure criterion, written so that others can run them.
    • That a failed test can be reported in full: the pre-registration, the script and all results are available.
    It does not show
    • That any translation holds or fails in general. One model, one task, one test.
    • That neuroscience results transfer to transformers. Transformers are fully observable, discrete, engineered systems; brains are partly observable, continuous and biologically constrained.
    • That the Jacobian proxy is causal. It is a sensitivity measure, and dense attention can make some efficiency statistics trivial.
    Next

    A positive result would need a scale-normalised edge, a null with enough freedom to move the statistic, and replication across models and tasks. Small-world scaling against density- and architecture-preserving nulls, and a comparison of patching-derived with activation-derived connectivity, remain untested.

    The main risk is the number of degrees of freedom. Graph construction, thresholding, symmetrisation, prompt selection and null choice can each change the answer. A useful report shows threshold sensitivity, separates signed from unsigned effects, controls for density, and keeps discovery apart from validation. Without these controls the import adds vocabulary but no explanatory pressure.
